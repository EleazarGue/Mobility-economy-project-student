Descripción:
Proyecto académico enfocado en evaluar la relación entre la eficiencia del tráfico vehicular y la productividad económica en áreas metropolitanas. Como parte del entrenamiento en Análisis de Datos, desarrollé un flujo completo de procesamiento e integración de datos utilizando datos reales de geolocalización e indicadores socioeconómicos.

Logros y Tecnologías Clave:

Procesamiento e Integración de Datos (ETL): Limpieza, estandarización y combinación de más de 1 millón de registros de tráfico (TomTom Traffic Index) con métricas socioeconómicas y ambientales (OECD Cities).

Tratamiento Avanzado con Python (pandas & NumPy): Limpieza de estructuras de texto complejas, normalización de formatos numéricos, conversión de tipos de datos (datetime y float) y tratamiento de valores nulos para garantizar la integridad analítica.

Agregación y Análisis Exploratorio: Cálculo de indicadores consolidados a nivel ciudad-año (filtrado en 2024) para identificar patrones de congestión, retrasos viales (mins_delay, jams_delay) y su correlación con el PIB per cápita y el desempleo.

Visualización de Datos (Matplotlib & Seaborn): Generación de gráficos analíticos para comunicar de manera efectiva hallazgos clave sobre patrones de movilidad y desarrollo urbano.

Aptitudes: Python · pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook · Limpieza de datos · Análisis exploratorio de datos (EDA)
